# 未上线小程序 · 模拟器调试指南

**不需要正式发布上线**，只要用微信开发者工具 + 已注册的测试 AppID，就能调试绝大部分功能。

---

## 1. 定位与「到达附近」

模拟器默认没有真实 GPS，任选一种方式：

### 方式 A：一键模拟（推荐）

1. 打开 **导览** 页
2. 点击顶部 **「模拟位置」**（仅模拟器显示）
3. 会模拟你在红头船展示点附近，列表出现距离，并可能弹出「收听讲解」

### 方式 B：开发者工具设坐标

菜单 **工具 → 位置信息 → 自定义**：

- 纬度：`23.462`
- 经度：`116.781`

然后点导览页 **刷新**。

---

## 2. 代替现场扫码（未发布也能测）

不能生成正式线下小程序码时，用 **编译模式** 代替扫码：

1. 开发者工具顶部 **普通编译** 旁下拉
2. 选择 **「测试-扫码讲解红头船」**（或导览页、AI 阿樟）
3. 点 **编译**

等价于打开：`pages/scenic-detail/scenic-detail?id=ship-museum&autoplay=1&from=scan`

---

## 3. 语音讲解 / AI 播报

**默认已关闭语音插件**（避免 `插件未授权` 报错），点击「播放讲解」会弹出 **文字讲解** 弹窗，功能可正常演示。

若要开启真实语音：

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → **插件管理** → 添加 **同声传译**
2. 将 `app.plugin.json.example` 里的 `plugins` 段复制进 `app.json`
3. 在 `utils/config.js` 中设置 `USE_WECHAT_TTS: true`
4. 重新编译；建议再用 **预览** 在真机测试

`utils/config.js` 示例：

```javascript
module.exports = {
  DEEPSEEK_API_KEY: '你的密钥',
  USE_WECHAT_TTS: false  // 本地开发保持 false
}
```

---

## 4. 功能对照表

| 功能 | 模拟器未上线 | 说明 |
|------|----------------|------|
| 页面浏览、AI 文字对话 | ✅ | 配好 `utils/config.js` 即可 |
| 距离排序、到达提示 | ✅ | 用「模拟位置」或自定义坐标 |
| 扫码进景点 | ⚠️ | 用编译模式代替 |
| 语音 TTS | ⚠️ | 需公众平台添加插件；建议真机预览 |
| 正式线下小程序码 | ❌ | 需发布体验版/正式版后生成 |

---

## 5. 比赛演示建议

答辩若用电脑：优先演示 **文字 + 模拟位置 + 编译模式扫码**，语音部分用手机 **预览** 播一段，避免模拟器插件偶发失败。
